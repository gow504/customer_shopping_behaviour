# customer_shopping_behaviour

## Customer Shopping Behaviour Analysis


# Project Overview


This project analyzes customer shopping behavior using transactional data to uncover patterns in purchasing, revenue, subscriptions, and demographics. The goal is to provide business-ready insights that support data-driven decision making.

The analysis combines data processing (Excel / SQL / Python) with interactive visualization (Power BI) to present insights clearly and concisely.

## Key Metrics
Total Customers: ~3.9K

Average Review Rating: 3.75

Average Purchase Amount: $59.76

These KPIs provide a quick snapshot of customer engagement and spending behavior.

# Analysis Performed

# Subscription Analysis

Compared subscribed vs non-subscribed customers
Identified subscription adoption trends

# Category Performance

Revenue and sales comparison across Clothing, Accessories, Footwear, and Outerwear
Clothing generates the highest revenue and sales volume

# Demographic Insights

Revenue and sales distribution by age group
Young adults contribute the highest revenue and purchase count

# Operational Insights
Customer behavior segmented by gender and shipping type
Helps identify preferred shopping and delivery patterns

Python (Jupyter Notebook) – Data exploration and preprocessing

SQL – Querying and structured data analysis

Excel – Initial data inspection and validation
